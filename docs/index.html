mi-epg

Guía de programación (EPG) en formato XMLTV, generada automáticamente cada 12 horas.

URL para el reproductor

Formato compatible con TiviMate:

https://antoniorb1913.github.io/mi-epg/epg.xml.gz

Formato XMLTV estándar:

https://antoniorb1913.github.io/mi-epg/epg-estandar.xml.gz

Cómo ponerla en TiviMate

  1. Ajustes → Guía de EPG
  2. Añadir fuente de EPG
  3. Dirección URL → pega la de arriba
  4. Guarda y actualiza
